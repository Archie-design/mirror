# 覺醒體系開運親證班 — 學員操作手冊

> 你的黃磚路：用每天的小小修練，走出屬於自己的桃樂絲故事。

---

## 一、歡迎篇

這是一個專屬於 **2026 覺醒開運親證班** 的線上修練平台。我們把整個課程比喻為《綠野仙蹤》中的黃磚路：每一次定課、每一次親證、每一次與旅伴互動，都是黃磚路上的一塊磚。系統會幫你記錄這些足跡，化為分數、連續天數與排行，讓修練變得清晰可見。

整本手冊以「點選哪裡、會發生什麼」為主軸，看完即可上手。

## 二、第一次使用

### 1. 登入方式
- 打開網址後，先用 **「姓名 + 手機末三碼」** 登入：
  1. 填寫你的姓名（與報名時一致）。
  2. 填寫手機號碼最後三碼。
  3. 系統會比對助教預先匯入的名單，比對成功即登入。
- 登入成功後，畫面上方會出現一條 **「綁定 LINE」提示橫幅**：
  - 點選後跳轉至 LINE 授權，完成綁定。
  - 綁定後，下次直接點「以 LINE 登入」即可一鍵進入，**不必再輸姓名 + 末三碼**。
- ⚠️ 直接點「以 LINE 登入」而尚未完成綁定 → 系統會提示「請先以姓名 + 手機末三碼登入後再進行綁定」。
- 第一次登入會引導你完成「旅人資料」與「找到旅伴」兩個步驟。

### 2. 旅人資料
- 填寫 **姓名、Email、生日**（生日選填，但建議填寫，後續會有生日特別任務）。
- 確認所屬大隊與小隊（由助教預先匯入名單，找不到請聯繫助教）。

### 3. 找到旅伴
- 系統會請你為「事業運／財富運／情感運／家庭運／體能運」自評 1–10 分。
- 直覺評分即可，系統會根據你的評分為你引出最相應的旅伴。
- 旅伴決定你的 **人生大戲（九宮格）模板**。
- 至於哪一運會召喚出哪位旅伴，留給你親身體驗 ✨

## 四、每日踏程（每天的修練）

### ⏰ 邏輯日規則
- **中午 12:00 前** 完成的任務，會被算進「前一天」。
- 例如：5/8 凌晨 2 點完成 d1，會被計入 5/7 的紀錄。
- 這是為了照顧「跨夜睡前才打卡」的同學。

### 1. 基本定課（d1–d8）
- 每項 **+200 分**，每天最多算 **3 項**。
- 項目：五感恩、餐前感恩、嗯啊吽、感恩冥想、抄經、光的冥想、欣賞、活在當下。
- 操作：點卡片 → 顯示「已完成」並即時加分。

### 2. 加權定課（p1–p5）
- 每項 **+500 分**，每天最多算 **3 項**。
- 項目：打拳、觀心書、大悲咒、子時入睡、痛參。
- 與基本定課 **分開計算上限**，所以一天最多 6 項定課。

### 3. 破曉打拳（p1_dawn）
- 完成 p1 打拳後，可額外勾選「同記破曉打拳」**+500 分**。
- 一天只能加成一次，不限定時段（過去曾限制中午前，現已開放全天可記）。

### 4. 飲食控制（diet_veg / diet_seafood）
- 三餐吃素 → **+500 分**
- 三餐海鮮素 → **+300 分**
- 一天擇一，不佔用前面的 3 項定課上限。

### 5. 撤銷
- 不小心打錯？點該項旁邊的撤銷按鈕，可移除最後一筆紀錄。

## 五、旅伴週報（每週任務）

> 「週」的計算：每週日 00:00 到下週六 23:59，以邏輯日計。

### 1. 破框練習（wk1）— 每次 +2000，每週上限 3 次
- 做不習慣、討厭、害怕的事，並在小群分享。
- 點卡片 → 簡述內容 → **即時入帳，不需審核**。

### 2. 天使通話（wk2）— 每次 +2000，每週上限 2 次
- 與夥伴進行天使通話。
- 點卡片 → 簡述心得 → **即時入帳**。

### 3. 線上小組凝聚（wk3_online）— +1000，每週 1 次
- 流程：
  1. 點「提交本週凝聚申請」→ 填寫補充說明（選填）。
  2. **小隊長審核**（一級審核）。
  3. 通過後即入帳。
- 若被駁回，可修正後重新提交。

### 4. 實體小組凝聚（wk3_offline）— +3000~5000，每週 1 次
- 流程：
  1. 小隊長現場出示 **凝聚 QR**。
  2. 學員打開 App → 在「旅伴週報」找到 QR 掃碼按鈕 → 掃描。
  3. 系統記錄到場名單。
  4. 結束後，小隊長 → **大隊長終審** → 一次入帳全員。
- 計分：
  - 出席 → +3000
  - 全員到齊 → 額外 +1000
  - 大隊長到場 → 額外 +1000
  - 最高 **+5000 分**。

### 5. 人生大戲分享（wk4_small / wk4_large）
- 小群分享（wk4_small）→ +2000，每週 1 次
- 大群分享（wk4_large）→ +3000，每週 1 次
- **必要條件**：當週至少完成 1 格九宮格，系統會自動檢核。

### 6. 臨時加碼任務（新流程）
- 由管理員臨時發布的活動任務（卡片會顯示在週報上方）。
- **二級審核流程**：
  1. 點任務卡片 → 上傳截圖 + 填寫日期與備註 → 提交。
  2. 卡片變 **琥珀色（審核中）**，等小隊長初審。
  3. 通過初審 → **藍色（初審通過）**，等大隊長終審。
  4. 通過終審 → **綠色（已入帳）**，分數到手。
- 若被駁回，可重新申請（卡片回復可點狀態）。

## 六、人生大戲（九宮格）

### 1. 旅伴模板
- 進入「人生大戲」分頁，會看到 9 格主題（依旅伴對應）。
- 每格代表一項生活實踐（例如「主動跟陌生人微笑」）。
- 模板由管理員設定，內容不可改。

### 2. 完成一格
- 完成該項實踐後，點該格 → 標記為「已完成」。
- **單格本身不計分**（只記錄完成）。

### 3. 連線加分
- 同一橫列、直行、對角線 3 格連線 → 立即 **+3000 分**。
- 連線可重疊（同一格可參與多條），最多 **8 條 = +24000 分**。
- 系統會自動偵測，無需手動觸發。

### 4. 旅伴運勢評分
- 頁面下方有 5 個滑桿（事業/財富/情感/家庭/體能）。
- 隨時調整，系統會自動計算最弱一運（不影響分數，只影響旅伴推薦）。

## 七、旅人榜（排行榜）

切換條件：
- **範圍**：個人 / 小隊 / 大隊
- **時段**：累積 / 本週 / 本月 / 過往（每週日中午 12:30 自動快照保存上週資料）

連續打卡天數（Streak）：
- 連續多日有任一打卡紀錄，會在名字旁顯示火焰標記。
- 漏掉一天即歸零。

## 十、親證曆（課程報名）

### 1. 報名流程
1. 進入「親證曆」分頁，會看到當期課程列表。
2. 點開某堂課 → 填寫姓名 + 電話末三碼 → 送出。
3. 系統產生 **入場憑證**：
   - 若該課程設定了外部報名連結（例如大師覺醒講座 → cchengroad.com）→ 顯示連結（請截圖或加書籤）。
   - 否則顯示 **QR Code**，現場由志工掃碼簽到。

### 2. 已報名後重新進入
- 重新打開該課程 → 直接看到先前的憑證或連結。

### 3. 志工掃碼入口
- 在課程頁底部有「志工入口」按鈕，輸入志工密碼後即可開啟掃碼器（學員不會看到此功能）。

## 十三、常見問題（FAQ）

**Q1. 為什麼我點完任務沒看到分數變動？**
- 檢查網路連線，重新整理頁面。
- 若是需審核任務（線上凝聚、臨時任務、一次性任務），分數要等審核通過才入帳。

**Q2. 不小心打錯一筆要怎麼撤銷？**
- 每日踏程：每張卡片右側有撤銷按鈕，可移除最後一筆。
- 一次性任務：申請若還是「審核中」可請小隊長駁回，再重投。
- 已通過審核後若有錯，請聯繫小隊長協助處理（或聯絡大法師調整分數）。

**Q3. 申請被駁回怎麼辦？**
- 在「我的旅程」可看到駁回原因，依說明修正後重新申請即可。

**Q4. 可以更改旅伴嗎？**
- 在人生大戲頁面下方，調整五運評分，系統會建議新旅伴。
- 但九宮格內容會跟著重置，**已完成的格子不會還原**，請審慎選擇。

**Q5. 中午 12 點前打卡為什麼算到昨天？**
- 這是「邏輯日」設計，照顧晚睡族群。
- 想隔天早上打卡前一天的進度，請在 12:00 前完成。

**Q6. 連續打卡（Streak）怎麼計算？**
- 邏輯日當天有任一筆 DailyLog（除一次性任務）就算當天有打卡。
- 漏掉一個邏輯日即歸零。

**Q7. 課程報名後 QR Code 不見了？**
- 重新打開親證曆 → 點該堂課 → 應該會自動顯示憑證（系統用瀏覽器 LocalStorage 記憶，請勿清除瀏覽器資料）。
